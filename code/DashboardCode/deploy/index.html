Solar Weather Station

A completely off-grid IoT environmental telemetry system featuring custom-routed hardware, low-power RF networking, and a full-stack interactive dashboard.

  • Decoupled RF Architecture Utilizes a low-latency ESP-NOW bridge to transition telemetry to the local network, drastically reducing battery drain compared to direct WiFi connections.
  • Aggressive Deep-Sleep Optimization Remote C++ ESP32 logic shuts off non-essential silicon (modems, LEDs) maintaining an ultra-low 4mA weighted average draw.
  • Fault-Tolerant Memory Buffers Prevents data loss during network dropouts using real-time RTC memory buffering on the edge node and local SD Card CSV logging.
  • Bespoke Hardware Enclosures Features a custom PCB and a 3D-printed Stevenson screen designed in Fusion 360 to ensure true thermal isolation for the BME280 sensor.
